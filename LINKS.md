## Repository Links

### 1. Main Documentation Repository
- **URL:** https://github.com/RuaaThamer/rideau-canal-monitoring
- **Description:** This repository contains the complete system documentation for the Rideau Canal Real‑Time Monitoring project. It provides a comprehensive overview of the solution architecture, data flow, and implementation across all project phases. The repository includes detailed explanations of the IoT sensor simulation, real‑time stream processing with Azure Stream Analytics, data storage using Azure Cosmos DB and Blob Storage, and the deployed web dashboard.
All required screenshots demonstrating system functionality (Phases 1–3), architecture artifacts, Stream Analytics query logic, and deployment evidence are included. This repository serves as the primary reference for understanding how sensor data is ingested, processed, stored, visualized, and deployed in a cloud‑based, real‑time monitoring system.
### 2. Sensor Simulation Repository
- **URL:** https://github.com/RuaaThamer/rideau-canal-sensor-simulation
- **Description:** This repository contains the IoT sensor simulator code for the Rideau Canal Real‑Time Monitoring project. It implements configurable virtual sensors that simulate environmental conditions such as ice thickness, surface temperature, snow accumulation, and external air temperature across multiple canal locations. The simulator sends real‑time telemetry to Azure IoT Hub using secure device authentication and serves as the data ingestion source for downstream real‑time analytics and monitoring components.


### 3. Web Dashboard Repository
- **URL:** https://github.com/RuaaThamer/rideau-canal-dashboard
- **Description:** This repository contains the web dashboard application for the Rideau Canal Real‑Time Monitoring project. It implements a Node.js and Express backend API that retrieves aggregated sensor data from Azure Cosmos DB and serves it to a responsive frontend interface. The dashboard presents real‑time ice safety status, environmental measurements, and location‑based summaries for multiple canal segments, and is deployed to Azure App Service with continuous integration and deployment using GitHub Actions.
