## Phase 2 – Real‑Time Processing with Azure Stream Analytics

### Phase 2 Overview

In Phase 2, raw sensor telemetry ingested through Azure IoT Hub is processed in real time using **Azure Stream Analytics**.  
This phase applies time‑based aggregations, evaluates ice safety conditions, and routes processed data to multiple storage destinations.

The goal of this phase is to transform continuous raw telemetry into meaningful, structured insights that can be queried, visualized, and archived.
